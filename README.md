# Web Scraper Python

Um web scraper que extrai dados de sites automaticamente.

## O que faz?
- Conecta em um site
- Extrai dados (título, preço, etc)
- Salva em arquivo CSV (tipo Excel)

## Como usar?

```bash
pip install requests beautifulsoup4
python scraper.py
```

Resultado: arquivo `livros.csv` criado!

## Tecnologias
- Python 3
- Requests (conexão web)
- BeautifulSoup4 (leitura HTML)
- CSV (salvar dados)

## Exemplo de Saída
Arquivo CSV com:
- Título do livro
- Preço
